Webhook-API-Schlüssel erstellen

Einen neuen API-Schlüssel für eine Creaves-Instanz zur Authentifizierung von Webhook-Anfragen generieren.

Nächste Schritte nach der Erstellung:
  1. Kopieren Sie den auf dem nächsten Bildschirm angezeigten Schlüssel (er bleibt abrufbar — der vollständige Wert wird auf der Seite API-Schlüssel und auf der Schlüsseldetailseite angezeigt).
  2. Öffnen Sie in der Quell-Creaves-Instanz Verwaltung → Synchronisation (/sync_configuration), fügen Sie dort ein Synchronisationsziel hinzu, aktivieren Sie es, und hinterlegen Sie diesen Schlüssel sowie die Webhook-URL dieser Konsole.
