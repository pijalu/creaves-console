Webhook-API-Schlüssel erstellen

Einen neuen API-Schlüssel für eine Creaves-Instanz zur Authentifizierung von Webhook-Anfragen generieren.

Nächste Schritte nach der Erstellung:
  1. Kopieren Sie den auf dem nächsten Bildschirm angezeigten Schlüssel (er wird nur einmal angezeigt).
  2. Gehen Sie in der Quell-Creaves-Instanz zu Konfiguration → Webhook-Konfiguration, aktivieren Sie den Webhook, fügen Sie diesen Schlüssel ein und setzen Sie die Webhook-URL auf /webhook/events in dieser Konsole.
