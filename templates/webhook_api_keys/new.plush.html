Create Webhook API Key

Generate a new API key for a Creaves instance to authenticate webhook requests.

Next steps after creation:
  1. Copy the key shown on the next screen (it is shown only once).
  2. In the source Creaves instance, go to Config → Webhook Configuration, enable the webhook, paste this key, and set the webhook URL to /webhook/events on this console.
