Créer une clé API webhook

Générer une nouvelle clé API pour qu'une instance Creaves authentifie les requêtes webhook.

Étapes suivantes après création :
  1. Copiez la clé affichée à l'écran suivant (elle n'est affichée qu'une seule fois).
  2. Dans l'instance Creaves source, allez dans Config → Configuration webhook, activez le webhook, collez cette clé, et définissez l'URL du webhook vers /webhook/events sur cette console.
