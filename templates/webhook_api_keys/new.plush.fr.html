Créer une clé API webhook

Générer une nouvelle clé API pour qu'une instance Creaves authentifie les requêtes webhook.

Étapes suivantes après création :
  1. Copiez la clé affichée à l'écran suivant (elle reste récupérable — la valeur complète est affichée sur la page Clés API et sur la page de détails de la clé).
  2. Dans l'instance Creaves source, ouvrez Administration → Synchronisation (/sync_configuration), puis ajoutez une cible de synchronisation, activez-la, et collez cette clé ainsi que l'URL webhook de cette console.
