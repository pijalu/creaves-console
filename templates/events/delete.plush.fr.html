Supprimer les événements webhook

Supprime définitivement les événements reçus des instances Creaves. Chaque événement supprimé est d'abord archivé dans un fichier JSONL.

Zone de danger

Cette action est irréversible depuis la console. Les événements archivés restent sur ce serveur sous forme de fichiers JSONL dans archives/event-deletions/.

Saisissez DELETE ALL pour tous les événements, ou l'ID d'instance exact pour une seule instance.
